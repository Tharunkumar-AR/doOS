✨ AI Assistant (optional, bring your own key)

This is the one deliberate exception to doOS being fully local. Everything else in this app stays on your device -- nothing is ever sent anywhere. If you turn this on, every time you ask for a daily insight or an AI-estimated task duration, a small, compact snippet of your schedule/task data is sent directly from your browser to whichever provider you pick below, using an API key you provide and pay for yourself. doOS never sees or stores that key anywhere but this browser's local storage, and nothing is sent unless you explicitly click a button that asks for it.

Fill In Missing Estimates

Finds every flexible (non-fixed-time) task that doesn't have an Est. Hours yet, and asks the AI to predict one for each -- grounded in the task's type, course, and your own past durations for similar work where you have any. Processed in batches of several dozen tasks per API call, not one call per task.

🎓 Canvas Integration (optional, bring your own token)

Browser build limitation: Canvas doesn't allow direct requests from a browser-based app like this one (confirmed -- its hosted instances never send the CORS headers a browser requires, and there's no opt-in the way some AI providers have). The desktop (Tauri) app routes around this through its own native networking and works fully; the plain browser build will show a clear error instead of silently doing nothing.

Paste in your institution's Canvas URL and a personal access token (Canvas -> Account -> Settings -> "+ New Access Token"). Used only to call your own institution's Canvas API directly from your browser with your own token -- doOS never sees or stores it anywhere but this browser's local storage.

Once connected, map a Canvas course to a doOS course from that course's own edit screen (Courses & Life). Each mapped course can be synced individually from there, or all at once below.

🖥️ Desktop App

doOS lives in the menu bar -- click the tray icon (or from anywhere) to clock in/out of whatever you were most recently tracking without switching windows.

🌱 Example Starter Data

doOS loads a small example term/courses/tasks automatically the very first time you open it with nothing in it yet -- no manual steps, and it never re-loads itself over real content you've since added. If you want to get back to that example layout (e.g. after clearing everything, or just to see it again), use this button. This replaces whatever is currently in the app.

📅 Calendars

Import a .ics calendar file, or try subscribing to a feed URL. Most calendar providers (Google, Outlook, iCloud) block direct browser fetches with CORS -- if subscribing fails, download the .ics from your provider and use "Import File" instead. URL-based calendars refresh only when you click Refresh, not automatically.

💾 Backup

Every change saves to this browser's local storage the instant you make it -- there's no "unsaved" state that a closed tab could lose. What local storage can't survive is clearing this browser's site data, reinstalling, or switching to a different browser/device. An exported JSON file is the only thing that protects against that -- export one regularly.

Local Auto-Backups

doOS also keeps up to 5 recent snapshots inside this browser automatically (roughly every 10 minutes of active use), so a bad import or bug can be rolled back without needing a manual export. These live in the same browser storage, though -- they're a safety net for in-app mistakes, not a substitute for the export above.
